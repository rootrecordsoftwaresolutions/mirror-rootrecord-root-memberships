# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/memberships` | Membership sync status and reload | `rootmemberships.admin` | `/memberships [status/reload]` |
| `/pro` | Pro membership purchase links and details | `rootmemberships.pro` | `/pro` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `rootmemberships.admin` | Reload memberships config and view sync status | `op` |
| `rootmemberships.pro` | View Pro purchase links and weekly award details | `true` |
